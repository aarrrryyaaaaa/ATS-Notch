# ATS-Notch — Ketentuan Penggunaan

ATS-Notch dikembangkan oleh **aarrrryyaaaaa** ([github.com/aarrrryyaaaaa/ATS-Notch](https://github.com/aarrrryyaaaaa/ATS-Notch)).

- ATS-Notch berjalan secara lokal di perangkat Windows Anda tanpa telemetri maupun analitik.
- Fitur jaringan opsional (cuaca, lirik, pembaruan, dan integrasi AI) hanya menghubungi layanan resmi terkait saat diaktifkan.
- Token akun AI dan Google OAuth Client ID disimpan secara lokal terenkripsi menggunakan Windows DPAPI (`CurrentUser`).
